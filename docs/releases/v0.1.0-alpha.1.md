# Superscience v0.1.0-alpha.1 — research workbench preview

Bring papers, code and research evidence into one local workspace. This first public prerelease contains source and launch media; it does not contain signed desktop installers.

## What is included

- A bilingual, illustrated project guide, architecture map, contributor templates and reproducible synthetic-data starter.
- Explicit **Open local tools** access when no model is available, while AI actions require a verified provider/model.
- A bundled editor that opens files and notebooks without fetching editor code from a CDN.
- Go and frontend security updates, portable integration-test fixtures and repaired CI prerequisites.
- Original Chinese narrated launch films in 16:9 and 9:16, with real application captures, synchronized captions and reproducible video source under `media/launch`.

## Evidence and limits

Real acceptance covers Jupyter execution, a live Crossref search, approved artifact creation, provenance and local share replay. The configured model provider returned HTTP 503, so this release does not claim successful real-model acceptance. The 51 figure counts registered scientific connectors, not 51 independently verified live services.

Local verification passed: 21 Go package race suites, frontend types/build, 12 unit tests and 10 browser tests. Dependency audits and reachable-code vulnerability checks passed with the documented unused OpenPGP advisory.

See [the validation record](../readme/validation.md) for checks and remaining limitations. Synthetic measurements are not benchmarks. The voiceover is synthetic. Permission approval is not an OS sandbox.

## Getting started

Follow the [README](../../README.md) or [中文指南](../../README.zh-CN.md). Choose **Open local tools** for files, search and notebooks; configure a working provider when you want AI assistance.

Apache-2.0 applies to original project source and original launch assets. Dependencies and external data retain their own terms; see [third-party notices](../../THIRD_PARTY_NOTICES.md).
