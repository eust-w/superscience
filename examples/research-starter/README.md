# Research starter

A small reproducible demonstration for Superscience. Every row in `measurements.csv` is **synthetic demonstration data**, not a measured benchmark or a scientific result.

Open this folder as a project, browse the CSV, and run `python3 analysis.py` from this folder in the terminal. For the notebook panel, copy the standalone code cell from `analysis.ipynb`; it embeds the same synthetic CSV and does not depend on the kernel working directory. Both use only the Python standard library.

Expected results: 10 trials, mean latency 125.20 ms, median latency 124.50 ms, sample standard deviation 5.69 ms, and 90% success. These numbers describe this invented sample only.

For a separate live literature demonstration, search Crossref for `robot learning`, retain the returned source links, and save a selected result as an artifact. Live results vary over time and do not validate the synthetic measurements.
